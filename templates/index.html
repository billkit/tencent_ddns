⏰ 定时任务设置

Linux/macOS 使用 crontab，Windows 使用任务计划程序。

配置路径： {{ cfg.LOG_FILE }}
如果日志路径没有写入权限，可以改为 ~/tencent_ddns.log
🐧 Linux / macOS (crontab)

运行 crontab -e 编辑定时任务：

每 5 分钟检查一次（推荐）：

*/5 * * * * /usr/bin/python3 /root/tencent_ddns_ui/app.py --port 8877 >> /var/log/tencent_ddns.log 2>&1

每 10 分钟检查一次：

*/10 * * * * /usr/bin/python3 /root/tencent_ddns_ui/app.py --port 8877 >> /var/log/tencent_ddns.log 2>&1

每小时检查一次：

0 * * * * /usr/bin/python3 /root/tencent_ddns_ui/app.py --port 8877 >> /var/log/tencent_ddns.log 2>&1
🪟 Windows 任务计划程序

创建基本任务，触发器设为"按预定时间"，操作选择"启动程序"：
程序：python
参数："C:\path\to\tencent_ddns_ui\app.py" --port 8877
起始位置：C:\path\to\tencent_ddns_ui

🧩 systemd 服务 + 定时器（进阶）

创建 systemd 服务单元实现更可靠的后台运行：

1. 创建服务文件：sudo nano /etc/systemd/system/tencent-ddns.service

[Unit] Description=Tencent Cloud DDNS Service After=network.target [Service] Type=simple User=root ExecStart=/usr/bin/python3 /root/tencent_ddns_ui/app.py --port 8877 Restart=on-failure RestartSec=60 [Install] WantedBy=multi-user.target

2. 创建定时器：sudo nano /etc/systemd/system/tencent-ddns.timer

[Unit] Description=Tencent Cloud DDNS Timer (every 5 min) [Timer] OnBootSec=1min OnUnitActiveSec=5min Unit=tencent-ddns.service [Install] WantedBy=timers.target

3. 启用并启动：

sudo systemctl daemon-reload sudo systemctl enable --now tencent-ddns.timer sudo systemctl status tencent-ddns.service
